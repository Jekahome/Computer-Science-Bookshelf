# Разное

## Задача управления когнитивной нагрузкой.

Методы снижения детализации, инструменты автоматической навигации и модели абстракции.

1. **Майкл Физерс — «Эффективная работа с унаследованным кодом»** (*Working Effectively with Legacy Code*)
Фундаментальная книга о том, как безопасно исследовать, покрывать тестами и менять код, который сложно понять и в котором нет документации.
2. **Диомидис Спинеллис — «Чтение кода на примере проектов Open Source»** (*Code Reading: The Open Source Perspective*)
Книга сфокусирована именно на навыке эффективного чтения, поиска и анализа чужого исходного кода.
3. **Джон Оустерхаут — «Философия проектирования программного обеспечения»** (*A Philosophy of Software Design*)
Объясняет, как бороться со сложностью системы, создавать «глубокие» модули и снижать когнитивную нагрузку при разработке.
4. **Саймон Браун — «Software Architecture for Developers»**
Практическое руководство по документированию и визуализации архитектуры с помощью модели C4.
